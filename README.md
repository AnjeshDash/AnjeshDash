## 🌟 My Core Focus & Passion

I’m a **Backend Software Engineer** specializing in **Java and Spring Boot**, focused on building **secure, scalable, and production-ready backend systems**.

My work revolves around **REST API design, authentication & authorization, microservices communication, and performance-driven architecture**.

* 🔐 **Security-First Development:** Hands-on with Keycloak, JWT, OAuth2, and RBAC.
* 🧩 **Microservices Architecture:** Kafka-based async workflows, gRPC sync communication.
* 🚀 **System Design Mindset:** Clean architecture, service boundaries, scalability.
